# Projekt: Task Manager

---

## Poznámky

- Nebyl jsem si zcela jistý, jak konkrétně se mají ty testovací scénáře vytvořit. Nakonec je to uděláno formou již hotové (odladěné) aplikace, která byla úspěšně otestovaná a je tedy připravená k odevzdání (všechny TC jsou pass). Je ale třeba přiznat, že v průběhu vytváření TC (a testování aplikace podle nich) jsem objevil několik chyb, které bylo třeba následně opravit.
- Při odevzdávání se objevila informace, že mám zkontrolovat zda se dá na zadané URL podívat i z privátního okna. Trocha googlování mi řekla, že něco takového není možné, pokud je repozitory nastavené jako privátní a to i v případě, že někomu pošlu odkaz a dokonce i když někoho označím za kolaborujícího. Jak jsem pochopil, tak u anonymního okna nelze ověřit totožnost tedy ani oprávnění. Tedy jsem repozitory změnil na veřejné.
